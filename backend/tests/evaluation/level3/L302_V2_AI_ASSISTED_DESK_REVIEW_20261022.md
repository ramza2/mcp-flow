## 2. 종합 검토 의견 — AI 초안

- **설계상 커버리지:** 조회 6건, 신규 생성 4건, 수정 4건, 원문 보존 4건, 모호한 요청 2건. 원문 인용·날짜·범위·월·업무상태·명시 엔터티 출처·비멱등 쓰기 위험 등 다양한 해석 조건이 포함된다.
- **중점 검토 4건(R05/C01/C02/E03):** R05 필터 보존, C01의 멱등성 허용 범위, C02의 마감시각과 예약시각 구분, E03의 인용문 내부 시각 오해 가능성. 모두 **LLM 관측 실패가 아니라 정답 설계 시 사전 검토할 사항**이다.
- **후보 개선:** 생성 행위에서 `IDEMPOTENT_WRITE`를 허용하는 범위는 실제 Agent/MCP Tool 구현에 멱등성이 보장되는지 확인한 뒤 판단하는 편이 적절하다. 기존 v2 gold를 사후 점수 조정 목적으로 완화하면 안 된다.
- **한계:** 이 정답셋은 사람 검토 전이며 ChatGPT가 정적 검토만 수행했다. 모델 응답을 본 적이 없으므로 '20건 모두 정상 분석', '성공률 100%', '독립 검증 완료'라는 결론을 낼 수 없다.
- **승인 전 점검:** 과제 담당자의 개별 정답셋 확인, 검토 의견에 따른 수정 여부 결정, 모델 호출 전 파일 SHA-256/버전 동결, 외부 사업에서 요구하는 평가 인증·검토 인원 요건 확인이 필요하다.

> 자연어 업무지시 분석 성능의 자체 검증을 위해 총 20건의 신규 시험문장을 구성하였다. 시험문장은 정보 조회 6건, 작업 생성 4건, 정보 수정 4건, 원문 반환 4건, 의도 불명확 2건으로 구성되며, 의도·요구 기능·엔터티·출처·날짜/시간·위험도·모호성·스키마 등 8개 평가 요소를 정의하였다. AI 보조 예비 검토를 통해 날짜의 역할, 조회 조건 보존, 입력 문자열 무변형 반환, 쓰기 위험도 등 사전 확인 항목을 식별하였다. 실제 성능 측정 결과는 별도 실측 증적과 검토·판정 결과에 따라 기록한다.

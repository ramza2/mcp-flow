# L3-02 v2 내부 자체평가 절차 간소화 — 방법론 변경 제안(미승인)

**상태: PROPOSED / 미승인 / 아직 적용되지 않음**

## 0. 배경과 변경 사유

- 현행 `METHOD_L302_V2.md`는 2026-10-21 과제 담당자가 승인한 방법론이다.
- 현행 방법에는 **실제 사람 2명**의 신규 gold 독립 검토, 측정 후
  서로 다른 사람 2명의 의미 판정, 필요 시 제3자 이견 조정이 있다.
  `scoring_l302_v2.py`와 `collect_l302_v2.py`가 이를 승인 게이트로 강제한다.
- 업무 운영상 이러한 검토 인력 확보가 어렵다는 의견이 있어
  **허위 검토 기록 대신, 검증 목적에 맞게 실제 수행 가능한 내부 자체평가**
  방법으로 사전 변경하는 안을 제안한다.
- **주의:** 위 2인 조건이 외부 기관의 의무인지 확인한 증거는 아직 없다.
  만일 협약·평가계획서·제출요령에서 외부 2인 독립검토를 강제하면
  이 단축안으로 해당 의무를 대체할 수 없다. 외부 요건 확인 전에는
  정식 외부 검증에 준한다고 기술하지 않는다.

## 1. 간소화된 절차(제안)

1. **AI 보조 정답셋 사전검토:** `L302_V2_AI_ASSISTED_DESK_REVIEW_20261022.md`
   의 설계상 쟁점을 검토한다. AI의 문서 검토를 인간 검토자나
   독립 검증기관으로 표기하지 않는다.
2. **실제 과제 담당자 1인 확인:** 20건 문장·정답을 직접 확인한 뒤
   검토자/확인 일시, 이견에 대한 결정, 승인 Git SHA를 남긴다.
   다른 사람이 대신 확인했다고 기록하지 않는다.
3. **평가 전 동결:** 신규 gold 파일·채점 기준·실행 코드·목표
   `85%`의 SHA-256, 승인 Git SHA를 보관한다.
4. **라이브 측정 1회:** 실제 운영 `qwen3-14b`의 분석 경로로
   20건을 한 번씩 평가한다. 실패·오류도 분모에 포함한다.
   원문 출력은 제한된 private 경로에 보관하고 공개 증적에는
   해시/검증 결과만 남긴다.
5. **문항별 의미 판정 1인:** 과제 담당자 또는 지정 실제 내부 평가자가
   승인된 8개 기준별로 판정한다. AI는 각 문항에 '판정 제안'과
   비교 근거를 작성할 수 있지만 **최종 판정의 주체로 가장하지 않는다**.
6. **내부 자체평가 결과 보고:** 계산기에서 17/20 이상이면
   `INTERNAL_MET`, 아니면 `INTERNAL_NOT_MET`와 같이
   **독립 검증과 구분되는 라벨**로 기록한다.
   실제 공식 제출 시에는 승인된 지표 정의·제출양식 요구사항에 맞춰
   다시 적합성을 확인한다.

## 2. 현행 방법론 대비 차이

| 구분 | 기존 승인 v2 (변경 없음) | 간소화 제안 (별도 버전 필요) |
|---|---|---|
| 용도 | 2인 독립 의미 검증 | 내부 자체평가 |
| 정답셋 사전 검토 | 실제 2인 독립 | AI 초안 + 실제 담당자 1인 확인 |
| 모델 출력 의미 판정 | 실제 2인 + 불일치 시 제3자 | AI 보조 제안 + 실제 평가자 1인 확정 |
| 문항 수와 목표 | 20건 / 성공률 85% | **동일** |
| 판정 항목 | 8개 모두 충족 | **동일** |
| 모델 호출/증적 | 실제 실행/해시 | **동일** |
| 보고 표현 | 독립 검토(실행됐을 때만) | 내부 자체평가(수행 사실만) |
| 코드 | `scoring_l302_v2.py`의 2인 게이트 | **별도** `scoring_l302_internal.py` 신규 구현 필요 |
| 기존 gold/40·30·50% | 불변 | **불변** |

## 3. 시스템 변경은 별도 PR로 수행

- **현재 `dataset_l302.v2.yaml` 상태 `PENDING_REVIEW` 유지.**
- 승인 전에는 `scoring_l302_v2.py`의 `independent_reviews` 2인
  요구를 완화하거나 가상의 reviewer metadata를 입력하지 않는다.
- 담당자가 이 **방법론 변경 자체를 별도 승인**하면,
  `level3-natural-language-analysis.internal.v1` 등
  **구분 가능한 별도 평가 버전·채점기**를 사용한다.
  이때 1인 검토 사실과 실제 승인 이력을 남기도록 fail-closed 게이트 구현.
- 문항 gold는 담당자의 **개별 검토/확인 이후 별도 승인**해야 한다.
  방법론 변경 승인만으로 20개 정답셋 승인 완료 처리하지 않는다.
- 새 버전에서 측정한 점수를 과거 v1 점수와 동일 기준의
  연속 향상치처럼 비교하지 않는다.
- 명칭이나 판정 코드는 외부 제출용 성능지표 준수 여부를
  자동 보증하지 않는다. 외부 요건에 맞지 않으면 내부 참고로만 활용한다.

## 4. 보고서용 사실 기반 문장 예시

> 자연어 업무지시 분석 정확도 평가를 위해 총 20건의
> 독립 신규 문장에 대해 의미 정답과 8개 평가 요소를 사전 정의하였다.
> AI 보조 사전검토 및 내부 책임자 확인 절차를 적용하고, 시험 실행
> 전 데이터셋과 채점 기준을 동결하는 자체평가 체계를 계획하였다.
> 실제 측정의 성공률과 목표 충족 여부는 모델 호출 증적 및
> 문항별 판정이 완료된 후 결과값에 따라 작성한다.

**위 문장은 '계획하였다'가 사실인 단계에서만 사용하고,
미실시 검토를 '완료하였다'로 바꾸지 않는다.**

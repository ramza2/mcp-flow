# L3-02 v2 신규 정답셋 독립 검토 기록 양식

**사용 목적:** 2026-10-21 승인된 방법론에 따른 v2 정답셋 20건의 사전 검토. **지금은 검토자 미지정·미수행, 정답셋 미승인** 상태이다. 이 양식은 검토를 수행하거나 승인한 증빙이 아니다.

## 검토 규칙

- **검토자 1과 2는 서로 다른 실제 사람**이어야 하며, 각자 상대 평가와 LLM 출력·성공률을 보지 않고 `dataset_l302.v2.yaml` 및 `GOLD_REVIEW_L302_V2.md`를 독립 검토한다.
- 필수 체크: (1) 문장·업무 의미 일치 (2) business capability 도메인·동작 (3) 엔터티 이름·값 (4) 사용자 명시 출처 (5) 날짜·시각·기간 의미 (6) 위험 분류 (7) 모호성·필요 확인 (8) StructuredRequestV1 계약 적합성.
- `적합 / 수정 필요 / 판단 보류` 중 하나를 **20개 문항별로** 적고, 적합이 아닌 문항에는 이유와 수정안을 적는다. 단순 '전체 승인' 서명은 세부 검토의 대체물이 아니다.
- **특히 확인:** R04 기간 양 끝, R06 월 전체, C02 마감 시점과 생성 예약 구분, E03 인용문 중 시각, A01·A02 미지정 업무의 추가 확인, 새 문항과 구버전 동형 반복 여부.
- 검토 완료·이견 정리 후 정답 문항을 고쳤다면 다시 검토받고 **모델 호출 이전** 데이터셋 SHA-256·채점 기준·승인 일시를 동결한다.
- 문항/정답은 공개 테스트용 합성 예시다. 검토표에 실제 고객 정보, 모델 원문, 비밀 토큰을 넣지 않는다.
